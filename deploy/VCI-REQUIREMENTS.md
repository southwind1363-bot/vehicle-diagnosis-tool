# 新規購入VCIに向けた開発・受入条件

確認日: 2026-09-08。利用者は開発に合わせて新しいVCIを購入する予定。既存機器待ちでは開発を止めない。これは購入候補を絞る条件であり、発注指示や実車互換の保証ではない。

## 最初に仕上げる経路

Windows PC → Web Serial → USBシリアルのELM327/STN互換VCI → 標準OBDの読み取り専用診断を先行する。無線・iPhone署名・ベンダーDLLを最初の利用開始の前提にしない。機種名に応じた診断判定を追加せず、VCIは通信経路として扱う。

| 購入前に確認する条件 | 現在の実装との対応 | 受入時に必要な確認 |
| --- | --- | --- |
| WindowsでUSBシリアル/COMとして認識できる | navigator.serial.requestPortとport.openを使用 | 正規ドライバー、対象ポート、他アプリとの排他 |
| 公開されたELM互換コマンド仕様がある | 初期化はATZ、ATE0、ATL0、ATS0、ATH1、ATSP0 | 実際の応答、行終端、プロンプト、時間切れ処理 |
| 現在のUART速度を確認できる | 38400/115200/9600 bpsを通常画面と詳細画面で共用 | 説明書・現在設定と選択値の一致。自動探索はしない |
| 対象車両の電気・OBD仕様に合う | 対応PIDに基づく標準読取と取得状態の区別 | 対象車の車種・年式・仕様・電源条件を個別確認 |
| 仕様書・サポート・正規販売経路がある | 未取得や矛盾を診断結果と混同しない方針 | 型番・ファームウェア・出所を記録。表示名だけで正規性を判断しない |

実装根拠: [script.js](script.js) の接続処理、initializeElmDeveloperAdapter、読取コマンド許可範囲。接続設定の変更はホスト側ポートを開く速度の選択であり、VCIの永続設定を書き換える機能ではない。

## メーカー資料から確認できた候補

- **OBDLink EX:** メーカーはWindows/USBと標準OBD-IIプロトコルを明記している。PC USBの調達候補として照合を進められる。ただしFord向け拡張機能の説明はFORScanとの組合せの説明であり、本ツールにその機能が実装済みであるという意味ではない。[製品仕様](https://www.obdlink.com/products/obdlink-ex/)
- **OBDLink SX:** メーカーはWindows/USBと標準OBD-IIプロトコルを明記している。候補にはなるが、調査時点のメーカー直販表示は在庫なし。発注時は在庫・保証・配送地域を再確認する。[製品仕様](https://www.obdlink.com/products/obdlink-sx/)

メーカーは開発者向けにAT/STコマンドの資料を公開している。上の候補は資料上の接続方式が開発経路に合うという評価であり、本ツールでの実機適合確認済みリストではない。[開発者資料](https://www.obdlink.com/developers/)

速度は機種名だけで固定しない。メーカーの過去の技術記事にもファームウェア更新に伴う初期速度変更例があるため、購入品の現在設定を確認する。記事は2010年の資料であり、現在の全機種の初期速度を断定する根拠にはしない。本ツールから記事中の速度書換え・永続保存コマンドを送信するものではない。[メーカー技術記事](https://www.scantool.net/blog/switching-communication-baud-rate/)

## 受入の進め方

1. 購入前: 型番・正規販売元・Windowsドライバー・通信仕様・保証条件を照合する。まだ互換確認済みとは呼ばない。
2. 車両接続前: PC起動、保存済みJSONの表示・保存・復元、配布物の整合性を確認する。VCI認識の確認と車両通信は区別する。
3. 対象車が決まった後: 適用条件・整備書・安全手順を確認し、利用者が接続と読取の実施可否を判断する。実車の初回読取を自動実行しない。
4. 読取後: 取得済みと未取得を区別し、保存したJSONから結果を再確認する。車種・VCI・ファームウェア・通信速度ごとに実測結果を残す。

正常0件と無応答、切断と終了未確認は別々に検証する。異常応答での自動再送、DTC消去、サービス実行、VCIの設定書換えを受入確認のために開放しない。

## この選定で解決しないもの

J2534実transport、メーカー独自診断、全ECUスキャン、iPhone接続、DTC消去・サービス実行は、それぞれの実装と適合確認が別途必要。高機能VCIを購入するだけでは利用可能にならない。価格・在庫・対象車の適合は購入時に再照合する。
