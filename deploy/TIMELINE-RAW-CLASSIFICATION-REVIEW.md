# ライブ推移の未換算数値除外（承認済み・本体適用）

2026-10-10 / 旧版 Web 3.13.655 / 適用版 Web 3.13.656

適用確認への「続けて」を受けて、検証済みの修正案を本体へ適用した。

## 確認した問題

ライブ推移の比較・グラフは有限の数値かどうかだけを確認しており、数値型の値に decoded:false が付いた記録も比較対象に入る。正規化済みの過去記録を保持する経路で再現した。数値型textやraw_hexについても、通常の数値として差分やグラフを作る場合がある。

現行本体を読み込んだ検証で再現した事実であり、実車試験や不正な車両データを確認したという意味ではない。

## 適用した変更

| 対象 | 3.13.655 | 3.13.656 |
| --- | --- | --- |
| 比較対象 | 有限の数値 | 既存のnumericCount分類で数値に数えられる値 |
| グラフ | 有限の数値が2点以上 | RAW/textを除外した数値が2点以上 |
| RAWと通常値の組合せ | 両方が数値なら差分を作る | 比較対象にしない |
| 通常の数値・0 | 比較・表示する | 維持する |
| 保存サンプル、値、時刻、ID、分類 | 保持 | 保持。削除・自動換算しない |
| 取得条件・時刻の比較可能フラグ | 既存条件で判断 | 維持。数値の比較件数とは区別する |

例: エンジン回転数0→100 rpmと、未換算の数値999→1000が同時に保存された2時点の記録では、比較対象2→1項目、グラフ2→1系列になる。回転数の差分+100 rpmと、未換算を含む保存サンプルは維持する。

実装は、buildLivePidTimelineSummary内の3つの候補選択で buildMonitorValueSummary([item]).numericCount === 1 を使用し、buildLivePidTimelineChartRowsの数値選択でもdecoded:false、未換算フラグ、raw_hex/textを除外する。保存schema・車両要求・実行許可は変更しない。

旧形式の記録を読み込んだ場合も元データを保持する。ただし現在値として再計算する比較件数・差分は減ることがある。診断結果の契約に影響するため、適用前に変更内容と隔離検証結果を提示して確認した。

承認前は本体のコピーをVM内で変更し134項目とブラウザー比較を実施した（timeline-raw-proposal-prHEJf）。承認後は本体コードを直接検査する回帰検証に切り替え、全体OBD検証にも組み込んだ。検証ファイル名は既存参照のため維持する。

- node deploy/scripts/validate-timeline-raw-proposal.js: 本体134項目合格。通常値、0、RAW/text、数値とRAWの前後組合せ、条件・単位・ECU不一致、入力不変を確認。
- 3.13.655生成の正規化済み記録と保存JSONの必要項目を固定fixtureに保存。旧記録の読込・再保存で、値・時刻・ID・分類を保持する。
- --browser: 本体を実JSONファイルから読み込み、数値だけの1系列/比較1項目、0の選択、390/1280px明暗、保存復元を確認。RAWだけのファイルへ置き換えた際に以前のグラフが残らず、記録自体は残ることも確認。
- 本体ブラウザー成果物: timeline-raw-proposal-YMU8jI。
- ブラウザーで本体コードの置換は行わない。車両要求なし。正規化処理・保存schemaは変更していない。

未正規化の特殊な旧形式でRAWフラグが正規化前に失われる問題の有無、別ネットワーク経路のグラフ分離、全PID換算は今回の検証範囲外。
