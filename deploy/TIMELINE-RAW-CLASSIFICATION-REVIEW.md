# ライブ推移の未換算数値除外案（本体未適用）

2026-10-10 / 現行 Web 3.13.655 / 承認待ち

## 確認した問題

ライブ推移の比較・グラフは有限の数値かどうかだけを確認しており、数値型の値に decoded:false が付いた記録も比較対象に入る。正規化済みの過去記録を保持する経路で再現した。数値型textやraw_hexについても、通常の数値として差分やグラフを作る場合がある。

現行本体を読み込んだ検証で再現した事実であり、実車試験や不正な車両データを確認したという意味ではない。

## 提案する変更

| 対象 | 現行 | 修正案 |
| --- | --- | --- |
| 比較対象 | 有限の数値 | 既存のnumericCount分類で数値に数えられる値 |
| グラフ | 有限の数値が2点以上 | RAW/textを除外した数値が2点以上 |
| RAWと通常値の組合せ | 両方が数値なら差分を作る | 比較対象にしない |
| 通常の数値・0 | 比較・表示する | 維持する |
| 保存サンプル、値、時刻、ID、分類 | 保持 | 保持。削除・自動換算しない |
| 取得条件・時刻の比較可能フラグ | 既存条件で判断 | 維持。数値の比較件数とは区別する |

例: エンジン回転数0→100 rpmと、未換算の数値999→1000が同時に保存された2時点の記録では、比較対象2→1項目、グラフ2→1系列になる。回転数の差分+100 rpmと、未換算を含む保存サンプルは維持する。

実装案は、buildLivePidTimelineSummary内の3つの候補選択で buildMonitorValueSummary([item]).numericCount === 1 を使用し、buildLivePidTimelineChartRowsの数値選択でもdecoded:false、未換算フラグ、raw_hex/textを除外する。保存schema・車両要求・実行許可は変更しない。

旧形式の記録を読み込んだ場合も元データを保持する。ただし現在値として再計算する比較件数・差分は減ることがある。診断結果の契約に影響するため、本体適用前にユーザー確認を行う。

## 検証済み範囲

- `node deploy/scripts/validate-timeline-raw-proposal.js`：134項目合格。
- 本体ソースのコピーだけをVM内で変更し、通常値、0、RAW/text、数値とRAWの前後組合せ、条件・単位・ECU不一致、入力不変、現行版保存→修正案復元→再保存を確認。
- `--browser`：同じ旧保存JSONを現行/修正案へ実際のファイル選択で読み込み、比較件数と系列数2→1、スライダーの0値選択、390/1280px明暗、保存復元と元サンプル保持を確認。
- ブラウザー成果物: `timeline-raw-proposal-prHEJf`。ローカルrouteでメモリ上の案を配信。外部・車両要求なし。
